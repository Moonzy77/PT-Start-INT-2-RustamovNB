# Задание 3. Мониторинг открытых сообщений

Программа на Python собирает публикации об информационной безопасности из открытых RSS-лент или читает сохранённые данные. Она удаляет дубликаты, предварительно определяет категории сообщений, ищет названия компаний и домены, группирует похожие публикации и сохраняет результаты.


## Запуск

Из сохранённой выборки:

```bash
python3 monitor.py --from-csv publications.csv
```

Из базы первого задания:

```bash
python3 monitor.py --from-db ../Задание_1/data/articles.sqlite3
```

Сбор свежих публикаций из BleepingComputer, The Record и Securelist (нужен интернет):

```bash
python3 monitor.py --live --out results_live
```

Параметр `--out` позволяет выбрать отдельную папку результатов, чтобы не перезаписывать предыдущий запуск.

## Входные данные

`publications.csv` содержит поля `source`, `date`, `title`, `url`. Поля `author` и `text` необязательны: если они присутствуют, программа их сохраняет. В исходной выборке есть только заголовки, поэтому отсутствующие описания и имена авторов программа не придумывает.

## Результаты

Файлы в папке `results` создаются автоматически при каждом запуске:

- `posts.csv` — публикации, их даты, авторы, заголовки, ссылки, категории, найденные компании, домены и номера групп.
- `events.csv` — предварительные группы похожих публикаций, ранняя дата в выборке, указанный издатель, количество публикаций и издателей, условный приоритет.
- `trend.csv` — число публикаций по датам.
- `monitor.sqlite3` — таблицы `posts` и `events` в SQLite.

В `posts.csv` поле `source` сохраняет источник получения данных. Поле `publisher` обозначает издателя: для Google News он определяется по окончанию заголовка вида `... - Издание`, если такое окончание есть. Поэтому `sources` в `events.csv` означает количество **различных указанных издателей**, а не подтверждённое число независимых первоисточников.

Классификация использует ключевые слова и регулярные выражения: сначала анализируется заголовок, затем аннотация при отсутствии подходящей категории в заголовке. Группировка приблизительная и требует проверки человеком. Дата `first_seen` показывает наиболее раннюю дату среди собранных публикаций, но не обязательно дату первого сообщения в интернете.
