# Задание 1. Оценка потенциальных целей

Программа собирает публикации из открытых источников и использует их для оценки интереса злоумышленников к выбранным компаниям.


### Запуск

Сбор публикаций из RSS-лент:

```bash
python3 collector.py
```

Дополнительный поиск новостей по компаниям:

```bash
python3 collector.py --search
```

Анализ публикаций и расчёт оценок:

```bash
python3 analyzer.py
```

### Файлы

- `collector.py` - сбор публикаций.
- `analyzer.py` - обработка публикаций и расчёт оценок.
- `companies.csv` - список компаний и параметры оценки.
- `data/articles.sqlite3` - база собранных публикаций.
- `results/review.csv` - таблица проверки публикаций.

После запуска анализатора в папке `results` создаются два файла:

- `rating.csv` - рассчитанные оценки компаний.
- `evidence.csv` - публикации, использованные при расчёте.

В расчёте учитываются записи из `review.csv` с подтверждёнными событиями и выбранной категорией злоумышленников.
