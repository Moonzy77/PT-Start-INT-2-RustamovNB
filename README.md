# PT Start INT-2 — Киберпогода и исследование киберугроз

Решение тестового задания PT Start по направлению «Киберпогода и группа дарквеб угроз».

В репозитории представлены три задания:

1. **Кто станет следующей целью?** — сбор открытых публикаций и оценка интереса разных категорий злоумышленников к компаниям.
2. **Атака через поставщика** — моделирование зависимостей сервисов и оценка возможных последствий инцидентов.
3. **Автоматизация мониторинга киберугроз** — сбор RSS-публикаций, классификация, удаление повторов и группировка сообщений.

Все программы написаны на Python 3 с использованием стандартной библиотеки.

В каждой папке находятся исходный код, входные данные, примеры результатов и README с инструкциями по запуску.

**Полный отчёт о выполнении тестового задания** представлен в PDF-файле `INT-№2 Рустамов Наиль Бахадыр оглы.pdf`, расположенном в корне репозитория. В нём описаны методология, использованные источники, реализация заданий и полученные результаты.
