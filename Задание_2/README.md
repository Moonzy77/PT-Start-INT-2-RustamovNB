# Задание 2. Модель зависимостей VK

Программа рассчитывает риски шести сценариев инцидентов и определяет, какие связанные процессы могут быть затронуты.

Для работы требуется Python 3. Дополнительные библиотеки не нужны.

### Запуск

```bash
python3 model.py
```

### Файлы

- `model.py` - расчёт рисков и построение графа.
- `nodes.csv` - организации, сервисы и процессы.
- `links.csv` - связи между узлами.
- `scenarios.csv` - сценарии инцидентов и оценки P, I, D.

Индекс риска рассчитывается по формуле:

R = P × I × D / 125 × 100

Показатели P, I и D задаются по шкале от 1 до 5.

### Результаты

После запуска в папке `results` автоматически создаются:

- `risks.csv` - оценки рисков и затронутые процессы.
- `graph.svg` - граф зависимостей между узлами.

Файл `graph.svg` можно открыть в браузере.

При изменении исходных CSV-файлов программа пересчитывает результаты и заново строит граф.
